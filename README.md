# 이음 메시지 일정 데모 0.2.16 · Windows x64

ZIP 하나를 다운로드하고 **모두 압축 해제**한 뒤 `install-demo.cmd`를 실행하세요.
필요한 파일은 ZIP에 모두 포함되어 있습니다. 따로 파일을 받을 필요가 없습니다.

스크립트가 내부 분할 파일을 자동으로 합치고 SHA-256을 확인한 후 압축을 풀어 데모를 실행합니다. 인터넷이나 Node.js 설치는 필요 없습니다. 기존 이음 설치본은 덮어쓰지 않습니다. 이 폴더의 app 아래에 무설치 데모를 풉니다. 이후에는 app/Ieum-Deadline-Demo-0.2.16-win-x64/Ieum-Deadline-Demo.exe를 실행하세요.

- 발신자와 수신자 모두의 캘린더에 시작 시간 없는 마감 일정 자동 등록
- 한국 발송일 기준 상대 날짜, 명시 시각 우선, 오전 중/점심 전 기본 12:05, 날짜만 있으면 16:00
- 날짜별 일과표의 4교시 종료 시간 적용 및 재동기화 중복 방지
- 이름 뒤 조직/내선 한 줄 표시, 작은 접속/부재/미접속 아이콘, 약 30px 행 높이
- 반·담임은 설정 화면에서 입력, 모달 X 닫기 영역 수정

서버 연결 없이 예시 데이터를 사용하는 데모입니다. 내 캘린더의 메시지 일정 체험에서 확인하세요.

Chromium·Linux Electron 화면 검증과 HTTPS/SQLite 통합 테스트를 수행했습니다. 이 빌드는 서명되지 않았으며 실제 Windows 실행은 아직 검증하지 못했습니다.

오늘 일정 버튼은 본창 위치·크기를 유지하며 설정한 왼쪽/오른쪽으로 패널을 슬라이딩합니다. 주 메뉴: 쪽지함, 대화, 내 캘린더, 교무업무, 학교소식, 바로가기. 교무업무에서 보강 안내/수업 변경/일과표를 선택하세요. 이름 더블클릭은 쪽지 작성, 사람 우클릭 → 대화는 대화창을 엽니다. 하단의 선택 쪽지/대화 버튼은 제거했습니다. 학교 이름을 누르면 조직도로 돌아갑니다.
