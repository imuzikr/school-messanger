# 이음 창 체험 데모 · Windows 10/11 x64

다운로드한 ZIP을 **모두 압축 해제**한 다음 `install-demo.cmd`를 더블클릭하세요. 나누어진 파일을 설치 파일로 합치고 SHA-256을 확인한 뒤 설치 프로그램을 실행합니다.

설치 후 바탕 화면의 **Ieum Window Demo**를 실행합니다. 브라우저 없이 작은 본창, 독립 대화창과 달력창을 체험할 수 있습니다. 서버나 계정 설정은 필요 없습니다.

예시 데이터만 사용하며 외부 AI·메신저 서버에 접속하지 않습니다. 캘린더 위치 선택, 시간대 드래그, 개별 수신자 선택과 제출 마감을 포함합니다.

설치 파일에는 코드 서명이 없습니다. Linux 클라우드에서 빌드와 화면 검증을 완료했지만 Windows에서 실제 설치·실행은 아직 검증하지 못했습니다.

GitHub 파일당 크기 제한 때문에 설치 파일을 나누어 제공합니다. 설치에 인터넷은 필요하지 않으며 PowerShell은 파일의 SHA-256 확인에만 사용합니다. 실패하면 실행하지 않고 중단합니다.

조직도 업데이트: **부서별·교과별·학년별·기타** 그룹과 들여쓰기된 하위 교직원 목록을 제공합니다. 학년·기타 정보가 없는 경우 미지정 그룹에 표시합니다. 기존 예시 프로필은 새 그룹 필드로 자동 보완합니다.

보강·일과표 업데이트: 조직도 위의 **보강 안내**에서 날짜·교시·내용·수신자를 지정하세요. **일과표**에서 특정 날짜의 임시 시간을 설정하면 보강 시간도 갱신됩니다. 임시 일과표 해제 시 기본 시간을 적용합니다. 데모는 예시 데이터로 동작하며 실제 PC 간 캘린더 자동 공유는 교내 서버·클라이언트 설치형에서 지원합니다.

업데이트 v0.2.1: 새 ZIP 전체를 별도 폴더에 압축 해제하고 install-demo.cmd를 실행하세요. 기존 데모 창은 작업 표시줄의 트레이 메뉴에서 종료하세요. 설치 완료 후 바탕 화면 아이콘으로 실행하면 조직도 위에 v0.2.1과 보강 안내·일과표 버튼이 표시됩니다. 이전 ZIP의 실행 파일은 업데이트되지 않습니다.

v0.2.2: 쪽지 작성 전용 창을 추가했습니다. 본창을 유지하며, 발송 성공 또는 취소 시 작성 창만 닫습니다. 전송 실패 시 내용을 유지하고 재시도할 수 있습니다. 새 ZIP 전체를 압축 해제하여 설치하세요.
