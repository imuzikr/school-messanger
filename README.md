ZIP 하나를 모두 풀고 install-demo.cmd를 실행하세요. 내부 파일을 자동 결합하고 해시 확인 후 데모를 실행합니다. 인터넷이나 Node.js 설치는 필요 없습니다. 기존 설치본은 덮어쓰지 않습니다.

메시지에서 추출한 항목은 오늘 일정 패널의 내 일정에 표시합니다. 회의·연수의 명시적 시간 범위는 시간대 블록으로, 기한은 실제 시각 위치에 점·선과 라벨로 표시합니다. 시작 시각만 있는 모임 안내는 기본 1시간 일정으로 등록합니다. 오늘 6시에 교무실로 모여주세요 → 오늘 18:00–19:00. 명시된 오전 6시는 06:00–07:00입니다. 오늘 10시까지 모여주세요 → 오늘 10:00 위치. 마감에는 종료 시간을 추가하지 않습니다. 제목·본문이 같아도 한 번만 등록합니다. 기존에 놓친 메시지도 재조회 시 반영하고 삭제 기록을 보존합니다. 이른 아침/저녁에는 시간축을 자동 확장합니다. 내일 1시에서 3시까지 교직원 연수 → 내일 13:00–15:00. 오전·오후 없는 시 표기의 1–7시는 학교 오후 시간으로 해석하며 24시간제와 명시된 오전·오후가 우선합니다.

캘린더 창은 고정하고 내부 패널만 부드럽게 움직입니다. 본창 위치·크기를 유지하며 설정에 따라 왼쪽/오른쪽으로 열립니다. 이름 앞 사람 아이콘으로 접속·부재·미접속을 구분합니다.

발송 저장 직후 최신 일정을 반영하며 앱 재실행은 필요 없습니다. 내일 일정은 내일 날짜를 선택해서 확인하세요. 모달이 열린 동안 받은 변경사항도 닫기 직후 표시됩니다.

서버 연결 없이 예시 데이터를 사용하는 데모입니다. 실제 Windows 실행은 미검증입니다.
