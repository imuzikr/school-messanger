# 이음 Windows 데모 0.2.24

ZIP 하나를 모두 풀고 install-demo.cmd를 실행하세요. 내부 파일을 자동 결합하고 해시 확인 후 데모를 실행합니다. 인터넷이나 Node.js 설치는 필요 없습니다. 기존 설치본은 덮어쓰지 않습니다. 기존 데모는 먼저 트레이의 ‘이음 종료’로 종료하세요.

일정 상세창의 ‘짧은 일정 요약’ 버튼을 누르면 아래로 접힌 페이지가 펼쳐집니다. 할 일 / 날짜·시간 / 장소 / 준비·확인을 로컬 규칙으로 정리합니다. 수정한 캘린더 시간도 요약에 반영합니다. 외부 통신이나 AI 모델 호출을 사용하지 않습니다. 장소를 인식하지 못하면 미기재로 표시합니다.

‘관련 메시지 보기’는 일정의 원본 메시지·대화를 보여줍니다. 발신자·발송 시각·원문·첨부파일을 확인하고 ‘일정으로 돌아가기’로 복귀합니다. 수동 일정에 원본 연결이 없으면 버튼을 표시하지 않습니다. 메시지·대화를 보내 자동 등록된 일정에서 체험해 보세요.

이전 기능도 포함합니다. 메시지함 선택과 이름/내용 검색은 목록 위에 있습니다. 시작 시간만 알리면 기본 1시간 블록, 마감은 실제 시간축의 점·선으로 등록합니다. 오전·오후 없는 1~7시는 오후로 해석합니다. 드래그로 일정을 이동하고 상하 가장자리로 시간을 조절합니다. 서버 연결 시 연결된 발신자·수신자·참조자 일정에도 시간 변경을 반영합니다. 같은 원본 재조회·재동기화 시 중복 등록하지 않습니다.

Windows 10/11 x64용 무설치 데모입니다. 서버 없이 예시 데이터를 사용합니다. 실제 Windows 실행은 미검증이며 Linux Electron 화면 테스트와 ZIP 파일 검증을 수행했습니다.
