오늘 일정과 조직도를 하나의 창으로 결합했습니다. 다른 앱이 두 영역 사이에 끼어들지 않고 함께 이동·최소화·숨김·복원됩니다. 조직도가 보이는 위치와 크기는 유지하며 설정한 왼쪽/오른쪽에서 자연스럽게 열립니다. 내 캘린더 작업 창과 메시지 작성·대화 창은 기존대로 유지합니다.
