# 이음 Windows 데모 0.2.59

[Windows 데모 전체 다운로드](https://github.com/imuzikr/school-messanger/archive/refs/heads/download/ieum-demo-0.2.59.zip)

1. 기존 데모를 종료합니다.
2. 다운로드한 ZIP **전체**를 새 폴더에 압축 해제합니다.
3. `install-demo.cmd`를 실행합니다.

스크립트가 포함된 실행 환경과 0.2.59 변경분을 검증하고 자동으로 조합해 실행합니다. Node.js 설치나 수동 업데이트는 필요하지 않습니다. `Ieum-0.2.55.part01/02`는 실행 환경 파일이며 완성된 앱의 버전은 **0.2.59**입니다.

메시지 작성 하단의 **캡처**에서 Windows 영역 캡처를 시작하고 **본문 삽입 / 파일 첨부**를 선택할 수 있습니다. 본문에서 Ctrl+V로 이미지 붙여넣기도 지원합니다. 이미지당 2 MB, 본문 이미지와 첨부 합계 3 MB 제한입니다.

중요 별을 키우고 보내는 사람·받는 사람·참조 사이에 옅은 구분선을 추가했습니다. 서버 목록은 이미지 원본을 제외하고, 메시지를 열 때 권한 확인 후 이미지를 가져옵니다.

검증: 단위 테스트 42개, 클립보드 붙여넣기/첨부/단독 발송/재시작 보존, 설치형 클라이언트의 서버 이미지 조회/표시/전달 검증 통과. 조합되는 모든 파일을 검증된 0.2.59 패키지와 대조했습니다. 실제 Windows 실행 및 캡처 도구는 미검증입니다.
