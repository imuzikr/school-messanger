# 이음 Windows 데모 0.2.30

ZIP 하나를 모두 풀고 install-demo.cmd를 실행하세요. 내부 파일을 자동 결합하고 해시 확인 후 데모를 실행합니다. 인터넷이나 Node.js 설치는 필요 없습니다. 기존 설치본은 덮어쓰지 않습니다. 기존 데모는 먼저 트레이의 ‘이음 종료’로 종료하세요.

일정 상세창의 ‘일정 요약’ 버튼을 누르면 윗면 경첩을 중심으로 노트북 커버처럼 3D 회전하며 열립니다. 버튼 문구와 크기는 펼치거나 접어도 일정하고, 다시 누르면 현재 각도에서 반대 방향으로 움직입니다. 할 일 / 날짜·시간 / 장소 / 준비·확인을 로컬 규칙으로 정리합니다. 수정한 캘린더 시간도 요약에 반영합니다. 외부 통신이나 AI 모델 호출을 사용하지 않습니다. 장소를 인식하지 못하면 미기재로 표시합니다.

‘관련 메시지 보기’는 일정의 원본 메시지·대화를 보여줍니다. 발신자·발송 시각·원문·첨부파일을 확인하고 ‘일정으로 돌아가기’로 복귀합니다. 수동 일정에 원본 연결이 없으면 버튼을 표시하지 않습니다. 메시지·대화를 보내 자동 등록된 일정에서 체험해 보세요.

이전 기능도 포함합니다. 메시지함 선택과 이름/내용 검색은 목록 위에 있습니다. 시작 시간만 알리면 기본 1시간 블록, 마감은 실제 시간축의 점·선으로 등록합니다. 오전·오후 없는 1~7시는 오후로 해석합니다. 드래그로 일정을 이동하고 상하 가장자리로 시간을 조절합니다. 서버 연결 시 연결된 발신자·수신자·참조자 일정에도 시간 변경을 반영합니다. 같은 원본 재조회·재동기화 시 중복 등록하지 않습니다.

오늘 일정과 조직도를 하나의 창으로 결합했습니다. 다른 앱이 두 영역 사이에 끼어들지 않고 함께 이동·최소화·숨김·복원됩니다. 조직도가 보이는 위치와 크기는 유지하며 설정한 왼쪽/오른쪽에서 자연스럽게 열립니다. 내 캘린더 작업 창과 메시지 작성·대화 창은 기존대로 유지합니다.

Windows 10/11 x64용 무설치 데모입니다. 서버 없이 예시 데이터를 사용합니다. 실제 Windows 실행은 미검증이며 Linux Electron 화면 테스트와 ZIP 파일 검증을 수행했습니다.

0.2.30: 일정 요약을 펼치면 상세창 전체가 부드럽게 위로 이동하면서 아래 요약 커버가 열립니다. 접으면 원래 중앙 위치로 돌아옵니다. 두 동작은 같은 애니메이션으로 연결되며 도중에 반전할 수 있습니다.

메시지함 창의 최소 너비를 1000px로 설정했습니다. 창을 줄여도 목록과 본문을 나란히 확인할 수 있습니다.

일정 입력·수정에 남아 있던 08:00~18:00 제한을 제거했습니다. 이른 아침·저녁 일정도 저장할 수 있습니다. 오후 11시는 23:00입니다. 같은 날의 종료 시간은 시작 시간보다 늦어야 합니다.

새 일정에서 종류 선택을 제거하고 날짜 오른쪽에 장소를 배치했습니다. 수신자를 선택하고 내용을 입력해 저장하면 선택한 사람들에게 메시지와 일정이 함께 전달됩니다. 수신자를 선택하지 않으면 개인 일정으로 저장합니다.
