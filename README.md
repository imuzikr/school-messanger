# 이음 Windows 데모 0.2.56

전체 ZIP을 압축 해제하고 기존 데모를 종료한 뒤 `install-demo.cmd`를 실행하세요. 파일 일부만 꺼내면 실행할 수 없습니다.

설치 스크립트가 검증된 0.2.55 실행 환경과 0.2.56 변경분을 자동으로 조합해 0.2.56을 실행합니다. Node.js 설치나 수동 업데이트가 필요하지 않습니다. 기존 사용자 데이터는 유지됩니다.

메시지 상세 제목을 제거하고 보내는 사람·받는 사람·참조의 3행으로 구성했습니다. 받는 사람은 한 줄을 넘을 때 더 보기로 펼치고, 참조는 모두 표시합니다. 공지 사항은 부서명을, 연결된 일정이 있는 메시지는 연한 주황색 일정 확인 태그를 표시합니다.

검증: 단위 테스트 41개 통과, Electron 메시지 헤더·공지 사항 검증 통과. 조합된 앱의 모든 파일을 원본 0.2.56 패키지와 대조했습니다. Windows에서의 실제 실행은 미검증입니다.
