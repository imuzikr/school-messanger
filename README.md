# 이음 Windows 데모 0.2.54

이 브랜치 ZIP 하나를 내려받아 압축을 푼 뒤 install-demo.cmd를 실행하세요. 같은 폴더의 두 part 파일을 자동으로 합쳐 해시를 확인하고 데모를 풉니다. part 파일을 각각 압축 해제하지 마세요. 기존 데모는 먼저 트레이의 이음 종료로 종료하세요. 기존 설치본과 예전 ZIP은 덮어쓰지 않습니다.

- 받는 사람 및 참조 목록은 최대 두 줄로 접고 더 보기/접기로 전체를 확인합니다. 모든 선택은 유지됩니다.
- 작성 방식은 일반 메시지 / 공지 사항 / 예약 메시지 / 일정 추가입니다.
- 공지 사항은 교사 전체 또는 행정 직원을 포함한 교직원 전체를 대상으로 하고, 발신 부서를 선택합니다.
- 공지의 예약 메시지와 일정 추가는 각각 켜고 끌 수 있는 알약 버튼이며 함께 선택할 수 있습니다.
- 학교 소식은 실제 공지를 모아 보여주며 발신 부서를 태그로 표시합니다. 카드를 누르면 전체 본문을 읽습니다.
- 예약 공지는 발송 전에 학교 소식에 나타나지 않습니다. 교내 서버에서 예약 시각에 메시지와 공유 일정이 함께 전달됩니다.
- 이전 자동 일정 인식/캘린더/부드러운 일정 요약/서식/미니멀 기능을 포함합니다.

Windows 10/11 x64용 무설치 데모입니다. 서버 없이 예시 데이터를 사용하며 실제 메시지는 전송하지 않습니다. 예약 메시지는 초안 저장만 체험합니다. 인터넷이나 Node.js 설치는 필요 없습니다.

Node 테스트 41개 및 Linux Electron 화면 검증을 통과했습니다. 공식 Windows Electron 런타임 해시, ZIP CRC 및 소스 일치를 검증했습니다. 실제 Windows 실행은 아직 미검증입니다.
