## 실행 및 테스트

Node.js 24 이상에서 `npm install`, `npm test`. Electron 개발 실행은 `IEUM_ROLE=demo`로 지정하고 설치한 Electron 44.7.0에서 이 폴더를 엽니다. package.json의 scripts는 추가했으나 Electron은 런타임 의존성으로 추가하지 않았습니다.

Windows 다운로드 데모는 `release/Ieum-Deadline-Demo-0.2.20-win-x64.zip`입니다. 모두 압축 해제한 뒤 `Ieum-Deadline-Demo.exe` 또는 `START-DEMO.cmd`를 실행합니다. 기존 0.2.7 설치 파일을 덮어쓰지 않는 x64 무설치 데모이며 Node.js/인터넷/교내 서버가 필요 없습니다. 내 캘린더의 ‘메시지 일정 체험’에서 본문과 한국 발송 시각을 입력하면 마감 일정이 보입니다. 같은 창에서 수신 체험을 반복해도 한 번만 등록됩니다. 새 창의 체험은 별도 메시지입니다.

빌드 재현: 공식 Electron 44.7.0의 `electron-v44.7.0-win32-x64.zip`과 같은 릴리스의 `SHASUMS256.txt`를 준비한 뒤 `python3 scripts/build-windows-demo.py <런타임 ZIP> <SHASUMS256.txt>`. 런타임 해시 검증 후 기존 산출물과 분리하여 ZIP을 만들고 해시를 기록합니다. 빌드 입력 다운로드만 외부 통신을 사용하며 일정 추출/데모 실행은 로컬 처리입니다.

배포 ZIP은 서명되지 않았습니다. 이 Linux 환경에서는 실제 Windows 실행과 SmartScreen 동작을 검증할 수 없었습니다. Linux의 브라우저/Electron 검증 및 ZIP의 PE 실행 파일·앱 리소스 확인 결과는 VALIDATION.md에 기록합니다.

요약을 펼치면 상세창 전체가 부드럽게 위로 이동하면서 요약 커버가 아래로 열립니다. 같은 애니메이션 진행률로 위치와 회전을 연결해 순간적인 재배치를 없앴습니다. 접으면 원래 중앙 위치로 돌아오고, 도중에 다시 누르면 현재 위치에서 반전합니다. 작은 창에서는 화면 안의 높이를 제한하고 동작 줄이기 설정을 따릅니다.

## 0.2.28 · 메시지함 최소 너비

메시지함 작업 창의 최소 너비는 1000px입니다. 창을 줄여도 메시지 목록과 선택한 본문이 나란히 보입니다. 기본 너비 1080px 및 다른 작업 창의 최소 너비는 유지합니다.

## 0.2.29 · 일정 입력의 시간 제한 수정

일반 일정 입력·수정에 남아 있던 08:00~18:00 제한을 제거했습니다. 같은 날짜의 이른 아침·저녁 일정도 저장할 수 있고 종료 시간이 시작 시간보다 늦어야 합니다. 서버도 이동 경로와 같은 유효 시각 검사를 적용합니다. 보강은 해당 날짜 일과표 시간을 계속 적용합니다.

## 0.2.30 · 일정 입력 간소화

새 일정은 단체 일정 방식으로 시작하며 종류 선택 대신 날짜 오른쪽에 장소를 입력합니다. 선택한 수신자에게 내용·날짜·시간·장소를 메시지로 발송하고 같은 일정을 공유합니다. 수신자를 선택하지 않으면 개인 일정으로 저장합니다. 기존 마감·보강 등 수정 시 내부 종류와 전용 필드는 유지합니다.

## 0.2.31 · 내 일정 버튼과 개인 일정 표시

오늘 일정의 내 체크리스트 버튼은 내 일정 등록 버튼으로 변경했습니다. 수신자 선택 없이 개인 일정 입력·수정하며 메시지를 보내지 않습니다. 직접 작성한 개인 일정은 노란 배경·진한 금색 가장자리·자물쇠와 개인 표시로 구분합니다. 메시지에서 자동 추출한 일정과 단체 일정은 기존 표시를 유지합니다. 기존 체크리스트 데이터는 삭제하지 않습니다.

## 0.2.32 · 주간/월간 전환과 오늘의 브리핑

주간 달력·월간 달력은 현재 캘린더 작업 창 안에서 교체되며 별도 달력 팝업이나 창 크기 변경이 없습니다. 기존 마감 요약 패널 대신 나의 할 일 체크리스트를 표시합니다. 앱 실행 후 로그인한 본창에서 오늘의 브리핑을 한 번 표시합니다. 한국 날짜 기준 오늘 일정의 시간·장소·준비 사항, 미완료 마감과 미완료 할 일을 공지처럼 정리합니다. 같은 실행의 화면 새로고침이나 창 복원에서는 반복하지 않고 종료 후 재실행하면 다시 표시합니다. 외부 AI 통신 없이 로컬 요약을 사용합니다.

## 0.2.33 · 마감 분류와 제출 마감 목록

제출·마감 안내·알려주기·보내주기 표현은 날짜나 시각이 있으면 마감으로 추출합니다. 회의 관련 단어가 있어도 업무 기한 표현을 우선 구분합니다. 자동 추출한 마감도 제출 마감 목록에 표시하며, 기존 시간축과 같은 항목이므로 완료 상태가 함께 반영됩니다. 재조회·재동기화 중복 방지는 유지합니다.

## 0.2.34 · 메시지함 가독성

목록 제목 17px, 내용 미리보기 15px(최대 두 줄), 발신자·날짜·검색 14px로 키웠습니다. 본문 기본값은 17px이며 사용자가 설정해 둔 본문 크기는 보존합니다. 상세 제목 22px, 메타정보 14px로 조정했습니다. 최소 너비 1000px의 목록/본문 배치는 유지합니다.

## 0.2.35 · 완료한 마감 표시 옵션

제출 마감 제목 옆의 완료한 일 표시를 끄면 완료한 항목을 목록에서 숨깁니다. 기본값은 표시이며 설정은 재실행 후에도 유지합니다. 다시 켜면 완료한 항목을 그대로 볼 수 있습니다. 항목과 완료 기록은 삭제하지 않습니다.

## 0.2.36 · 마감 원본 메시지와 주간 시간 범위

제출 마감 목록의 체크박스는 완료 여부만 변경합니다. 내용 버튼을 클릭하면 연결된 원본 메시지·대화를 열며 완료 여부는 유지합니다. 목록 보기에도 같은 동작을 적용합니다. 직접 등록하여 연결된 메시지가 없는 항목에는 안내를 표시합니다.

주간 달력은 기본적으로 22:00까지 표시하고 맨 아래에 종료 시간 눈금을 표시합니다. 더 늦은 기존 일정이 있으면 시간대를 확장해 보존합니다. 오늘 일정 패널의 시간 범위는 기존대로 유지합니다.

## 0.2.37 · 날짜별 일과표 제목과 기본 시간

교무업무의 일과표 창에서 적용 범위 선택을 제거하고 제목을 입력합니다. 지정한 날짜의 수정 시간과 제목을 저장하고, 입력한 제목·적용 날짜·교시 시간표를 전체 교직원에게 메시지로 발송합니다. 임시 일과표는 날짜를 정확히 일치시켜 사용하므로 다음 날에는 설정에 등록한 기본 일과 시간을 사용합니다. 다른 날짜에도 임시 일과표를 등록했다면 그 날짜의 값을 사용하며 과거 기록은 보존합니다.

설정 → 학교 일과표에서는 기본 일과 시간을 따로 저장합니다. 기본 시간 저장은 메시지를 발송하지 않습니다. 날짜별 수정은 기본 시간을 덮어쓰지 않습니다. 임시 일과표 해제 시 해당 날짜만 기본값으로 복원하고 안내 메시지를 발송합니다. 서버는 기존 일과표 데이터를 보존하면서 제목 필드를 추가합니다.

## 0.2.38 · 메시지 한 행 목록과 열 너비 조절

메시지 목록을 보낸 사람 / 제목 / 내용 앞부분 / 받은 날짜의 고정 순서로 한 행에 표시합니다. 제목을 별도 줄에서 반복하지 않으며 본문 앞부분의 공백과 줄바꿈을 정리해 내용 열에 표시합니다. 긴 텍스트는 말줄임하고 마우스를 올리면 확인할 수 있습니다. 중요 표시·첨부 표시·안 읽음 구분과 본문 열기는 유지합니다. 보낸 메시지함에서도 발신자 이름을 표시하며 수신 확인은 본문 상세에서 확인합니다.

제목 줄의 세 구분선을 드래그하면 양옆 열의 너비가 조절됩니다. 전체 너비는 유지하며 최소 열 너비를 보장합니다. 구분선에 포커스하고 좌우 방향키로도 조절할 수 있습니다. 너비는 로컬 설정으로 저장해 새로고침·새 창·앱 재시작에 유지합니다. 기존 기본 설정과 메시지 데이터는 보존합니다.

## 0.2.39 · 목록 글자 크기와 열 조절 포커스

메시지 목록의 보낸 사람·제목·내용·날짜 글자를 모두 15px로 맞추고 제목은 굵게 표시합니다. 본문 크기 설정은 유지합니다. 열 구분선을 마우스로 조절할 때 포커스를 강제로 남기지 않고 드래그 종료·취소 때 해제합니다. 키보드로 구분선을 선택할 때는 포커스 표시와 좌우 방향키 조절을 유지합니다.

## 0.2.40 · 메시지 상세 상단 압축

제목을 가장 위에 두고 안내 구분·인쇄 버튼을 같은 줄에 배치합니다. 발신자·발송 날짜/시간·수신자 정보는 바로 아래 한 영역에 모읍니다. 수신자 첫 이름과 인원 안내를 클릭하면 전체 이름과 읽음 상태를 펼쳐 확인합니다. 펼친 목록은 본문 영역을 밀어내지 않고 상세 영역 안에서 표시합니다. 긴 제목은 최대 두 줄로 표시하고 전체 제목은 툴팁에서 확인합니다. 상단과 본문 여백을 줄이고 본문 글자 크기 설정은 보존합니다.

## 받는 사람 선택 · 0.2.41

조직도에서 여러 사람을 체크한 뒤 선택한 사람의 이름을 더블클릭하거나 우클릭의 메시지 보내기를 선택하면 체크한 전체가 받는 사람에 들어갑니다. 체크하지 않은 사람을 더블클릭하면 그 사람만 지정합니다. 받는 사람·참조 검색 추천은 이름을 입력했을 때 표시하고 선택 직후 닫습니다. 빈 검색칸 포커스는 추천을 다시 열지 않으며, 외부 클릭·포커스 이동·Escape로 닫을 수 있습니다. Escape는 작성창을 닫지 않습니다.

## 메시지 상세 버튼 · 0.2.42

메시지 상세 하단의 연동된 일정/일정으로 등록 버튼을 제거했습니다. 메시지에서 일정 자동 추출·등록 및 원본 연결 데이터는 유지합니다. 삭제·회수·답장·전체 답장·전달 버튼은 기존대로 사용할 수 있습니다.

## 메시지 작성 방식 · 0.2.43

우클릭 메뉴는 인원 표시 없이 메시지 보내기로 통일했습니다. 선택한 전체 수신자는 유지합니다. 작성창의 별도 수신자 체크 목록과 하단 중요 메시지/직접 일정 추가/예약 체크박스·설명을 제거했습니다. 상단의 일반 메시지/예약 메시지/일정 추가 버튼으로 방식을 전환하고 제목·본문·수신자·첨부 및 입력한 선택 필드는 유지합니다. 일반 메시지는 기존 자동 추출을 사용합니다. 예약 메시지는 미래 예약 날짜·시간을 입력해 저장하며 실제 교내 서버가 예약 시각에 전달합니다. 서버 없는 데모는 예약 저장만 체험합니다. 일정 추가는 날짜·시작·종료·장소를 입력하고 메시지와 공유 일정을 함께 저장합니다. 받는 사람과 참조자가 일정 공유 대상이며 별도 자동 추출은 건너뛰어 중복하지 않습니다. 교무업무에서 시작하는 보강/수업 변경 기능은 유지합니다.

## 본문 입력 공간 · 0.2.44

작성창 하단 버튼을 취소/파일 첨부/보내기로 통일했습니다. 별도 큰 첨부 영역을 제거하고 본문 입력창이 남은 높이를 모두 사용하도록 했습니다. 긴 본문은 입력창 안에서 스크롤하며 하단 버튼 위치는 유지합니다. 파일 첨부 버튼으로 파일을 선택하거나 본문 영역으로 파일을 끌어놓습니다. 첨부 파일은 작은 목록에서 확인·삭제하며 기존 파일 크기 제한을 유지합니다. 상단 일반/예약/일정 추가 방식과 발송 동작은 유지합니다.
