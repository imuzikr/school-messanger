## 실행 및 테스트

Node.js 24 이상에서 `npm install`, `npm test`. Electron 개발 실행은 `IEUM_ROLE=demo`로 지정하고 설치한 Electron 44.7.0에서 이 폴더를 엽니다. package.json의 scripts는 추가했으나 Electron은 런타임 의존성으로 추가하지 않았습니다.

Windows 다운로드 데모는 `release/Ieum-Deadline-Demo-0.2.8-win-x64.zip`입니다. 모두 압축 해제한 뒤 `Ieum-Deadline-Demo.exe` 또는 `START-DEMO.cmd`를 실행합니다. 기존 0.2.7 설치 파일을 덮어쓰지 않는 x64 무설치 데모이며 Node.js/인터넷/교내 서버가 필요 없습니다. 내 캘린더의 ‘메시지 일정 체험’에서 본문과 한국 발송 시각을 입력하면 마감 일정이 보입니다. 같은 창에서 수신 체험을 반복해도 한 번만 등록됩니다. 새 창의 체험은 별도 메시지입니다.

빌드 재현: 공식 Electron 44.7.0의 `electron-v44.7.0-win32-x64.zip`과 같은 릴리스의 `SHASUMS256.txt`를 준비한 뒤 `python3 scripts/build-windows-demo.py <런타임 ZIP> <SHASUMS256.txt>`. 런타임 해시 검증 후 기존 산출물과 분리하여 ZIP을 만들고 해시를 기록합니다. 빌드 입력 다운로드만 외부 통신을 사용하며 일정 추출/데모 실행은 로컬 처리입니다.

배포 ZIP은 서명되지 않았습니다. 이 Linux 환경에서는 실제 Windows 실행과 SmartScreen 동작을 검증할 수 없었습니다. Linux의 브라우저/Electron 검증 및 ZIP의 PE 실행 파일·앱 리소스 확인 결과는 VALIDATION.md에 기록합니다.
