# 기타 업무 일정

교무업무 아래 **기타 업무** → 안전 지도 / 중식 지도 / 자율학습 지도에서 `.xlsx` 파일을 선택합니다. 첫 번째 시트만 읽습니다. 미리보기에서 확인한 뒤 **일정 등록**을 누릅니다.

먼저 **설정 → 교직원 정보 → 관리**에서 교직원 파일을 등록하면 업무별 담당자와 담임이 자동 연결됩니다. **기타 업무 담당자**에서 업무별 담당자를 확인·수정할 수 있고 담임은 교직원 표의 학년·반으로 관리합니다. 실제 서버에서는 관리자만 설정할 수 있고, 관리자 또는 해당 업무의 담당자만 업로드할 수 있습니다. 데모에서는 누구나 체험할 수 있습니다.

| 업무 | 엑셀 열 | 시간 |
|---|---|---|
| 안전 지도 | A 날짜 / B 생활 안전 담당 부서 교사 / C 그 외 교사 | 07:00–08:00 |
| 중식 지도 | A 날짜 / B 교사 이름 | 12:00–13:00 |
| 자율학습 지도 | A 날짜 / B 교사 이름 | 18:00–22:00 |

- 날짜는 Excel 날짜 셀 또는 `2026-10-15`, `2026.10.15`, `2026년 10월 15일`처럼 연도를 포함합니다.
- 첫 행에 제목(날짜, 이름 등)이 있어도 됩니다. 교사가 여러 명이면 쉼표로 구분합니다.
- 최대 5 MB, 배정 1,000행, 압축 해제 기준 20 MB까지 지원합니다. 구형 `.xls`는 Excel에서 `.xlsx`로 저장해 주세요.
- 업무별 담당자는 모든 업로드 날짜를 받고, 배정 교사는 자신이 배정된 날짜만 받습니다. 서버 업로더는 담당자나 배정 교사인 경우에만 본인 캘린더에 표시됩니다.
- 같은 업무·날짜를 다시 업로드하면 배정을 갱신하고 중복을 만들지 않습니다. 파일에 없는 날짜의 배정은 유지됩니다.
- 존재하지 않는 교사, 동명이인, 잘못된 소속/날짜가 있으면 오류 행을 표시하며 전체 등록을 막습니다. 이름은 교직원 등록 정보와 일치해야 합니다. 동명이인은 교직원 등록에서 구별할 수 있는 이름으로 정리해야 합니다.
- 담당자를 바꾸면 기존 업무 일정의 수신 대상에도 반영됩니다.
- 업무 일정 상세 화면에는 안전 지도 / 중식 지도 / 자율학습 태그를 표시합니다. 관리자 또는 해당 업무 담당자는 **편집** 버튼으로 날짜별 배정 교사를 수정할 수 있습니다.
- 저장하면 해제한 교사의 캘린더에서는 기존 배정이 빠지고 새 교사에게 표시됩니다. 업무 담당자는 계속 해당 일정을 받습니다. 날짜별로 교사를 교환해도 동일하게 반영됩니다. 안전 지도는 담당 부서 교사와 그 외 교사를 각각 한 명 이상 선택해야 합니다.
- 날짜·시간의 개별 변경·삭제·드래그는 지원하지 않습니다. 엑셀을 재업로드하면 그 날짜의 배정은 엑셀 내용으로 갱신됩니다.
- 현재 버전은 배정 가져오기와 갱신을 지원합니다. 엑셀에서 행을 지워도 기존 일정이 자동 삭제되지는 않습니다.

데모 데이터는 현재 PC에 저장되며 실제 교사에게 전송되지 않습니다. 실제 교내 서버에 연결하면 서버가 권한과 명단을 다시 검증하고 각 계정의 캘린더로 배포합니다.


## 교직원 통합 엑셀

첫 시트 A~I열을 `이름 | 보직 | 학년 | 반 | 내선번호 | 부서 | 업무 | 특별실 | 동아리` 순서로 작성합니다. 첫 행 머리글이 필요하며 이름과 부서는 필수입니다. 최대 1,000행/5 MB, 신규 계정 생성은 한 번에 200명까지 지원합니다.

- 이름으로 기존 교직원과 연결합니다. 동명이인은 기존 내선번호로 구분하며, 비활성 계정은 관리자에서 먼저 활성화합니다.
- 등록한 행의 빈 값은 기존 정보를 지웁니다. 파일에 없는 교직원과 해당 교직원의 배정은 유지합니다. 같은 반의 담임 중복이나 잘못된 값이 있으면 전체 등록을 중단합니다.
- 학년·반이 모두 있으면 담임으로 연결합니다. 학년만 입력하면 학년 정보만 등록합니다.
- 업무의 `안전 지도`, `중식 지도`, `자율학습 지도`는 각 업무의 전체 일정 수신 담당자를 지정합니다. 여러 업무는 쉼표·줄바꿈·세미콜론으로 구분합니다. `생활 안전 지도`, `자율학습`, `중식 지도 담당자` 등의 표기도 지원합니다. 그 외 업무 문구는 정보로 저장됩니다.
- 담당자 변경은 기존 업무 일정의 수신 대상에도 반영합니다. 날짜별 배정 교사는 유지합니다. 특별실·동아리도 저장하고 조직도 검색에 사용합니다.
- 실제 서버에서는 관리자만 등록할 수 있습니다. 신규 계정의 아이디와 임시 비밀번호는 등록 직후 **로그인 정보 다운로드**에서 CSV로 받아 교직원에게 전달합니다. 최초 로그인에서 비밀번호를 바꾸며, 기존 계정의 로그인 정보와 권한은 유지합니다. 임시 비밀번호는 서버에 평문 저장하지 않습니다.
- 데모에서는 신규 인원을 목록에 추가합니다. 실제 로그인 계정은 생성하지 않습니다.


## 메신저 관리 담당자 선택

**설정 → 기타 업무 담당자**는 메신저에서 해당 업무 일정을 등록·편집할 사람을 지정하는 화면입니다. **담당자 선택 부서**를 바꾸면 그 부서에 맞는 업무 카드와 해당 부서 교직원만 표시됩니다. 부서 선택은 조회 필터이며 소속 인원을 자동 배정하지 않습니다. 다른 부서로 이동해도 선택은 유지되고, 각 업무 아래에서 전체 선택한 담당자를 확인할 수 있습니다. 이 필터는 안전 지도 엑셀의 부서별 배정 구분을 변경하지 않습니다.


## 직접 편집과 부서별 관리 카드

교직원 정보 창은 처음부터 9열 헤더와 빈 입력 행을 제공합니다. **행 추가**로 파일 없이 입력하거나, 엑셀을 업로드한 뒤 셀에서 수정해 **저장**합니다. **기존 정보 불러오기**로 저장된 명단을 불러와 수정할 수도 있습니다. 기존 명단에서 이름을 바꿔도 계정 식별자와 로그인 정보는 유지합니다. **행 제외**는 이번 저장 대상에서 행을 뺄 뿐 계정을 삭제하지 않습니다. 변경하지 않은 학년·반과 업무는 기존 담임·관리 담당자 선택을 보존합니다. 보직은 계정 권한과 별도로 저장합니다. 기존 8열 파일은 보직을 비워 호환합니다.

| 선택 부서 | 표시하는 관리 카드 |
|---|---|
| 교무부 / 교무기획부 | 일과표, 보강/시간표 |
| 생활 안전부 / 학생생활부 | 안전 지도, 중식 지도 |
| 학년부 | 자율학습 지도 |

다른 부서로 전환해도 기존 선택은 보존합니다. 일과표 담당자는 관리자와 함께 기본·임시 일과표를 변경하고 일과표 안내를 발송할 수 있습니다. ‘반·담임’ 개별 설정 항목은 제거했으며 학년·반을 교직원 정보 표에서 관리합니다.

교직원 정보 관리는 메신저와 분리된 큰 창에서 열립니다. 창의 제목 영역을 끌어 이동하거나 가장자리를 끌어 크기를 조절할 수 있습니다. 작은 화면에서는 표를 가로로 스크롤할 수 있습니다. 이미 열린 창을 다시 열면 작성 중인 내용이 유지됩니다.

## 업무 교환 요청 (0.2.76)

- 캘린더의 배정 일정 상세에서 **업무 교환 요청**을 선택하거나 **기타 업무 → 업무 교환 → 새 교환 요청**을 엽니다.
- 자신의 배정과 같은 종류의 다른 날짜·교사를 선택하고 요청 사유를 작성합니다. 안전 지도는 생활 안전 담당 부서 소속끼리 또는 그 외 교사끼리 교환합니다. 다른 배정 교사들은 유지됩니다.
- 상대 교사는 수락 또는 거절할 수 있습니다. 수락하면 해당 업무 담당자 또는 관리자가 최종 승인·반려합니다. 요청자는 승인 전에 취소할 수 있습니다.
- 승인 전에는 기존 배정을 유지합니다. 승인 시 배정·시간·교직원 정보를 다시 확인하고, 새로 맡는 시간에 다른 일정이 겹치면 승인을 막습니다. 두 배정과 처리 상태는 하나의 서버 트랜잭션으로 저장합니다.
- 완료하면 두 교사의 캘린더와 담당자의 배정표가 함께 변경됩니다. 진행 상태·처리자·처리 시간·메모는 관련 교사와 현재 담당자/관리자만 조회할 수 있습니다. 진행 중인 배정이 직접 편집되거나 시간이 변경되면 요청을 자동 종료합니다.
- 다른 교사의 개인 캘린더는 공유하지 않습니다. 교환 선택에는 본인 배정과 관련된 업무 종류의 배정 정보만 제공합니다.
- **업무 교환** 목록과 기타 업무 메뉴의 숫자로 진행 건과 확인하지 않은 결과를 확인합니다. 접속 중 상태 변경은 알림으로 전달되고, 부재중 변경도 재접속 후 목록에 남습니다.
- Windows 데모에서는 목록 상단의 **체험 역할**로 요청 교사·상대 교사·담당자 역할을 바꿔 체험할 수 있습니다. 실제 설치형 클라이언트는 로그인한 계정의 권한만 사용합니다.

## 개인 포스트잇 메모장 (0.2.77)

메신저 본체 오른쪽 상단의 노란 **메모** 손잡이를 누르면 오른쪽으로 메모장이 미끄러져 나옵니다. 오늘 일정과 메모는 보조 영역을 전환해 사용하며 본체와 함께 이동·최소화됩니다. 오늘 일정의 설정된 위치는 유지됩니다.

- **새 메모**를 눌러 포스트잇에 바로 입력합니다. 최대 200개, 메모당 4,000자까지 입력할 수 있습니다.
- **목록 / 그리드**로 보기를 바꿀 수 있으며 보기 방식과 메모 순서도 저장합니다.
- 메모의 점 손잡이를 길게 누른 뒤 다른 메모 앞·뒤에 놓아 순서를 바꿉니다. 아래 삭제 영역에 놓거나 ×를 눌러 삭제할 수 있습니다. **되돌리기**로 최근 삭제를 복원합니다.
- 손잡이에 초점을 두고 **Alt+방향키**로도 순서를 바꿀 수 있습니다. 드래그 중 **Esc** 또는 창의 포커스 이탈은 이동을 취소합니다.
- 메모는 로그인 계정별로 이 PC의 앱 저장소에 자동 저장합니다. 메시지·대화·캘린더 데이터나 서버 동기화에 포함하지 않습니다. 다른 계정으로 로그인하면 그 계정의 메모장으로 전환합니다. 다른 PC로 자동 동기화하지 않습니다.
- 저장 실패 시 입력 내용은 화면에 유지하며 다시 저장할 수 있습니다. 저장된 기록이 손상된 경우 덮어쓰지 않습니다.

## 메모 편집과 담임 업무 (0.2.78)

메모 손잡이는 본체 오른쪽 바깥으로 살짝 돌출됩니다. 점 손잡이를 누른 채 바로 끌어서 이동·삭제할 수 있으며 길게 기다릴 필요가 없습니다. 새 메모는 큰 포스트잇 편집창으로 열립니다. 바깥을 클릭하거나 **_** 버튼을 누르면 작은 카드가 되고, 카드의 **↗ 확대** 버튼으로 다시 크게 편집할 수 있습니다. 변경 내용은 그대로 자동 저장됩니다.

오늘 일정 하단 **내 일정 등록** 오른쪽의 **담임 업무**를 누르면 수신한 담임 업무를 볼 수 있습니다. 메시지 작성 시 제목 아래 **공지 → 담임 → 마감…** 중 **담임**을 선택해 발송합니다. 별도 제목을 입력하면 그 제목을 유지하면서 담임 분류도 함께 저장합니다. 수신자를 자동으로 바꾸지는 않습니다.

여러 발신자가 보낸 내용은 수신자의 담임 업무 창에 발송 시각 순서로 누적되며, 발신자·날짜·시간·원문 내용을 표시합니다. **관련 메시지 보기**로 원본과 첨부를 확인할 수 있습니다. 예약 발송은 실제 전달된 뒤에 표시되며, 회수되거나 휴지통으로 이동한 메시지는 표시하지 않습니다. 담임을 선택하지 않고 제목만 ‘담임’으로 입력한 메시지는 자동 분류하지 않습니다.

### 0.2.79 담임 업무 고정

담임 업무의 날짜 오른쪽 ‘고정’을 누르면 본인의 캘린더 ‘완료 확인’에 메시지 제목과 원문 연결이 등록됩니다. 다시 누르면 고정을 해제합니다. 고정 날짜는 한국 시간의 오늘이며 시간은 미지정입니다. 완료 여부와 날짜는 기존 일정 상세 화면에서 변경할 수 있고, 변경 후에도 원문 연결과 고정 상태가 유지됩니다. 다른 교사의 완료 확인 목록에는 영향을 주지 않습니다.

‘오늘로’는 오늘 일정 상단 날짜 오른쪽에 표시됩니다. 하단에는 내 일정 등록과 담임 업무 두 버튼이 유지됩니다. 담임 업무는 보낸 사람·관련 메시지 보기·날짜·고정 버튼을 상단에 배치하고 줄 간격과 반복 빈 줄을 줄여 표시합니다. 원본 메시지의 내용은 보존합니다.

### 0.2.80 양쪽 날개

기본 배치에서 캘린더는 조직도 왼쪽, 메모는 오른쪽에 동시에 펼칠 수 있습니다. 각 날개를 닫아도 다른 쪽은 유지됩니다. 캘린더를 오른쪽에 배치한 설정에서는 메모가 반대쪽에 표시됩니다. 작은 화면에서는 양쪽 패널 폭을 조절하며, 화면 가장자리에서 필요한 경우에만 전체 창 위치를 보정합니다.

두 날개는 같은 속도로 미끄러져 나오고, 숨긴 영역은 다른 프로그램의 클릭을 막지 않습니다. 담임 업무의 설명 문구를 없애고 현재 펼쳐진 영역 가운데에 모달을 정렬했습니다. 손잡이 아래에는 테두리나 그림자가 남지 않도록 처리했습니다.

### 0.2.81 메모 서랍 손잡이

메모 손잡이는 닫혀 있을 때 본창 오른쪽에, 펼쳤을 때 메모 서랍의 바깥 끝에 붙어 표시됩니다. 열고 닫는 동안 서랍과 같은 속도로 함께 이동하며 손잡이를 다시 눌러 닫을 수 있습니다. 손잡이에는 테두리를 두지 않고 본창 경계선이 비쳐 보이지 않도록 처리했습니다.

### 0.2.82 메모 서식

확대한 메모 위쪽 도구에서 굵게, 기울임, 밑줄, 글머리 기호, 번호 목록을 선택할 수 있습니다. 글자를 선택한 뒤 서식을 적용하거나 서식을 켜고 입력하세요. Ctrl+B, Ctrl+I, Ctrl+U 단축키도 사용할 수 있습니다.

접힌 포스트잇에서도 같은 서식이 보이고 그대로 편집할 수 있습니다. 기존 일반 텍스트 메모도 유지되며, 서식을 포함한 메모는 계정별로 이 PC에만 자동 저장됩니다. 메모 본문은 기존과 같이 4,000자까지 입력할 수 있습니다.

### 0.2.83 설정 창 닫기

설정 창 오른쪽 위 X 버튼의 클릭 범위를 넓히고 직접 닫기 처리를 연결했습니다. 설정 내용이 길어 스크롤하더라도 헤더와 완료 버튼이 유지됩니다. 변경한 설정은 기존처럼 즉시 저장되며 X, 완료 버튼, Esc로 창을 닫을 수 있습니다.

### 0.2.84 메시지 수신 확인 알림

수신자가 메시지를 열어 확인하면 발신자의 본창에 ‘OOO님이 메시지를 수신했습니다’ 알림과 메시지 제목이 표시됩니다. 본창이 최소화되었거나 트레이에 있어도 Windows 알림으로 안내합니다. 참조 수신자도 포함하며, 같은 메시지를 다시 열어도 같은 사람에 대한 알림은 반복되지 않습니다.

발신자가 부재중일 때의 확인은 서버에 보관했다가 다음 접속 때 표시합니다. 첫 화면 브리핑이 열려 있다면 브리핑을 닫은 뒤 안내합니다. 알림 확인 기록은 서버가 관리하므로 서버 재시작 후에도 이미 처리한 알림을 다시 표시하지 않습니다. 수신 알림은 별도의 답장 메시지나 캘린더 일정을 만들지 않습니다. 실제 네트워크 동작에는 수정된 서버와 클라이언트를 함께 사용해야 합니다. 데모의 알림 테스트는 예시 표시입니다.

## 0.2.85 캘린더에서 업무 교환

- 내 캘린더에서 본인에게 배정된 안전 지도·중식 지도·자율학습 지도 일정 클릭 → 업무 교환 요청. 클릭한 일정은 고정되고 상대 일정·교사를 선택합니다.
- 기타 업무에는 업무 교환 버튼이 없습니다. 캘린더 상단 업무 교환은 요청 확인용이며 새 요청은 일정 상세에서 시작합니다. 진행 중인 일정 상세에서는 교환 요청 확인으로 이동합니다.
- 상대 교사 수락 → 업무 담당자 최종 승인 후 두 교사의 배정을 한 번에 바꿉니다. 일정 등록자는 담당자 설정이 바뀌어도 등록한 일정을 볼 수 있고, 교환 이후에도 갱신된 배정을 확인합니다. 등록자라는 이유만으로 승인 권한이 생기지는 않습니다.
- 등록자·현재 담당자·당사자에게 요청/수락/완료 등 상태별 본창 및 OS 알림을 표시합니다. 부재중에는 다음 로그인 후 최신 상태를 알립니다. 창 여러 개, 재접속, 반복 조회로 같은 상태를 중복 알리지 않습니다. 확인 상태는 계정별 서버 저장이며 서버 재시작 후에도 유지됩니다.
- 캘린더의 업무 교환 및 일정 상세의 교환 요청 확인에서 응답·승인·변경 이력을 확인합니다.

## 0.2.86 업무 달력

내 캘린더 → 업무 달력에서 안전 지도·중식 지도·자율학습 지도만 모은 월간 배정표를 봅니다. 업무별 색상, 시간, 배정 교사, 내 배정 및 진행 중인 교환을 표시합니다. 이전/다음 달과 이번 달 이동을 지원하고 등록되지 않은 날짜는 배정 없음으로 표시합니다.

학교 전체 업무 배정 정보는 모든 로그인 교직원이 조회할 수 있습니다. 공유 데이터는 업무 종류·날짜·시간·등록자·배정 정보로 제한되며 개인 일정, 원문 메시지, 첨부파일, 비공개 메모를 포함하지 않습니다. 개인 캘린더의 수신/배정 범위는 기존과 같습니다.

업무 달력에서 내 배정 클릭 → 업무 교환 요청으로 시작합니다. 다른 교사의 업무도 상세 열람할 수 있지만 대신 교환을 요청할 수는 없습니다. 상대 교사 수락 후 업무 담당자가 최종 승인한 시점에 교환이 완료되고, 두 교사와 등록자·담당자의 일정 및 알림에 반영됩니다.

## 0.2.87 일정 상세에서 교환 및 이번 달 대상

- 주간·월간·업무 달력 상단의 업무 교환 버튼 제거. 본인 일정 클릭 → 상세 모달의 업무 교환 요청으로 시작합니다. 진행 중인 요청은 해당 일정 상세의 교환 요청 확인에서 확인·수락·승인합니다.
- 교환 대상 목록은 한국 날짜 기준 오늘부터 이번 달 말일까지의 같은 업무 배정 교사만 표시합니다. 날짜가 지난 배정 및 다음 달 배정은 제외합니다. 가능한 대상이 없으면 안내를 표시하고 요청 보내기를 비활성화합니다. 서버도 새 요청의 대상 날짜 범위를 확인합니다.
- 업무 달력 카드에는 업무명·배정 교사·내 배정/진행 상태를 표시하고 시간은 생략합니다. 상세 화면의 실제 시간과 일정 충돌 검사는 유지합니다.

## 0.2.88 현재 사용자와 배정 교사 구분

업무 달력은 전체 배정표입니다. 현재 사용자가 교사A이고 배정 교사가 홍길동 2라면 그 일정의 교환 요청자가 될 수 없습니다. 업무 담당자의 전체 일정 열람·편집 권한도 다른 교사의 교환 요청 권한을 뜻하지 않습니다.

상세 화면에 현재 사용자·배정 교사·교환 가능 여부를 표시하고, 요청할 수 없는 경우에도 버튼과 사유를 보여 줍니다. 진행 중인 요청은 교환 요청 확인으로 처리합니다.

Windows 데모에서는 상세 화면의 데모 교환 요청자에서 배정 교사를 골라 체험할 수 있습니다. 이는 해당 모달의 체험 역할이며 실제 현재 사용자와 구분하여 표시합니다. 모달을 닫거나 다른 일정을 열면 체험 역할을 초기화하고, 달력의 내 배정 표시는 실제 현재 사용자를 기준으로 합니다. 실제 인증 클라이언트에는 이 선택기가 없으며 서버는 로그인한 본인의 배정만 요청하도록 검사합니다.

## 0.2.89 상대 일정에서 바로 교환 요청

업무 달력에서 교환할 상대 교사의 일정을 클릭 → 상세 모달의 교환 요청하기 → 변경 전후 날짜 확인 후 요청 보내기. 상대 날짜는 처음 클릭한 일정으로 고정됩니다.

교환 가능한 내 배정이 하나면 자동 연결하고, 여러 날짜가 있으면 내 날짜만 고릅니다. 상대 일정에 여러 교사가 있으면 같은 업무/안전 지도 담당 구분에 맞는 상대만 선택합니다. 대상과 내 배정 모두 이번 달의 오늘 이후 날짜를 사용하고, 지난 날짜·다음 달·이미 진행 중인 교환은 선택에서 제외합니다. 교환 가능한 내 배정이 없거나 본인 일정을 열었다면 이유를 안내합니다.

상대 수락 → 담당자 최종 승인 시점에 교환이 완료되며 등록자·담당자·두 교사의 캘린더와 알림을 함께 갱신합니다.

현재 사용자가 교사A이고 상대 배정이 홍길동 2라면 교사A의 다른 날짜 배정이 있어야 교환할 수 있습니다. 데모에서는 내 배정이 있는 교사를 요청자 역할로 선택해 체험할 수 있습니다. 실제 인증 클라이언트는 로그인 본인 배정만 사용합니다.

## 0.2.90 닫기 아이콘 테두리 통일

브리핑 등 모달이 열릴 때 닫기 아이콘에 자동으로 붙던 굵은 외곽 포커스 표시를 제거했습니다. 모달 자체에 초기 포커스를 주고, 사용자가 그 사이 입력 요소를 선택했다면 해당 포커스를 유지합니다.

모달과 메신저 창의 닫기 아이콘은 기본 테두리 없음·모서리 6px로 통일합니다. 키보드로 선택하면 1px 내부 포커스 선으로 위치를 표시합니다. 설정 창의 닫기 클릭 영역과 기존 클릭·Enter·Esc 동작은 유지합니다.

## 0.2.91 교환 상대 표시 단순화

일정 상세의 데모 요청자 전환 목록을 제거하고 현재 사용자를 유지합니다. 선택한 상대 일정에서 교환 가능한 배정 교사가 한 명이면 요청 창에 이름을 고정 표시합니다. 공동 배정으로 여러 명이 교환 가능할 때만 해당 배정 교사 중 선택합니다. 내 배정 날짜 선택 및 요청 내역의 수락·승인 체험 역할은 유지합니다.

## 0.2.92 교환 요청 카드 행 구분

업무 교환 목록의 카드는 상태, 업무명, 요청자 ↔ 상대 교사 이름, 교환 날짜를 각각 다른 행으로 표시합니다. 수락·승인 담당자와 요청 당사자 모두 같은 구성을 사용합니다. 상세의 교환 전후 비교와 승인 권한은 유지합니다.

## 0.2.93 개인 캘린더 업무 일정 고정

안전 지도·중식 지도·자율학습 지도는 담당자 권한과 관계없이 개인 캘린더 타임라인에서 날짜/시간 드래그 이동 및 위아래 경계 조절을 금지합니다. 조절 핸들과 드래그 안내도 표시하지 않습니다. 기존 canReschedule 값이 있는 일정도 고정합니다. 일반 개인 일정의 이동/조절, 업무 상세 열기·교환 요청 및 담당자의 배정 교사 편집은 유지합니다.

## 0.2.94 메모 카드 클릭 확대

그리드/목록의 작은 메모 본문 또는 카드의 빈 공간을 클릭하면 해당 메모를 큰 포스트잇으로 엽니다. 손잡이·삭제·확대 버튼은 각 동작을 유지하며, 손잡이 드래그는 메모 확대를 실행하지 않습니다. 서식과 자동 저장, 최소화 및 바깥 클릭 동작도 유지합니다.
